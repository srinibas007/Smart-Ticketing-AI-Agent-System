**Smart Ticketing – AI-Powered Support Ticket Management System**

An intelligent AI-powered ticket management system designed to automate support-ticket analysis, prioritization, skill matching, moderator assignment, and notifications.

Project Overview

Traditional ticket management systems often require administrators or support teams to manually:

Read and understand incoming tickets

Determine ticket priority

Identify the technical skills required

Assign tickets to appropriate support staff

Provide troubleshooting guidance

Notify assigned moderators

This project automates many of these activities using an AI-driven ticket-processing workflow.
The application combines React + TypeScript on the frontend with Node.js + Express.js + MongoDB on the backend. Google Gemini AI analyzes newly created tickets and generates useful technical information that helps moderators resolve issues faster.
